# Iron-Core Gym — Website Project

A fully static multi-page website built using vanilla HTML and CSS.
The project represents a modern gym called Iron-Core Gym, showcasing its services, membership plans, and contact information.

# Project structure

    IRON-CORE-GYM/
    │

    ├── styles/

        └── logos/

# Pages Included

- Page	Description
- Home (index.html)	Landing page introducing Iron-Core Gym.
- About	Details about the gym, mission, and facilities.
- Plans	Membership plans and pricing.
- Register	Form for new users to sign up.
- Contact	Contact information and communication form.

# Styling

All styling is done with pure CSS (no frameworks).

common.css contains shared global styles.

Each page has a dedicated CSS file for modularity.

# How to Run the Project

1. No setup or installation required.

2. Clone or download the repository.

3. Open index.html in any web browser.

4. Navigate using the menu links.
